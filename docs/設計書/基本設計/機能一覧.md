# 日報管理システム 画面別機能一覧

## 目的

基本設計は画面IDで分け、画面ごとに対応する機能IDを示す。ユーザーストーリーは複数画面を利用する業務の流れを示す。受け入れ条件は[詳細設計](../詳細設計/受け入れ条件.md)で管理する。

## ユーザーストーリー

| ストーリーID | 機能     | 利用ロール         | 目的・操作範囲                                                           | 基本設計                                |
| ------------ | -------- | ------------------ | ------------------------------------------------------------------------ | --------------------------------------- |
| US-001       | ログイン | 社員、上長、管理者 | 認証して日報管理を利用する。ログイン・セッション・ログアウトを含む       | [ログイン](ログイン/基本設計.html#spec) |
| US-002       | 日報検索 | 社員、上長、管理者 | 権限範囲内の日報を条件検索し、カレンダー・一覧・詳細で内容を確認する     | [一覧](日報検索/基本設計.html#spec)・[詳細](日報詳細/基本設計.html#spec) |
| US-003       | 日報登録 | 社員               | 自分の勤務・作業実績を記録し、登録済みの内容を修正する。登録・編集を含む | [登録](日報登録/基本設計.html#spec)・[編集](日報編集/基本設計.html#spec) |

## 利用条件と結果

| 機能     | 開始条件                                               | 主な結果                                                                   |
| -------- | ------------------------------------------------------ | -------------------------------------------------------------------------- |
| ログイン | 利用者の認証情報が登録されている                       | 自分の権限で日報管理を利用できる。ログアウト後はセッション無効             |
| 日報検索 | ログイン済み                                           | 権限範囲内の結果を表示する。該当日報がなくても検索でき、空の一覧を表示する |
| 日報登録 | 社員としてログイン済みで、必要なマスタ・社員設定がある | 新規登録または本人の日報の更新を保存し、検索から内容を確認できる           |

## 権限

- 社員は自分の日報のみ検索・参照・登録できる。編集は下書き（DRAFT）・差戻し（REJECTED）に限る。承認待ち（PENDING）・承認済み（APPROVED）は参照のみとする。
- 上長は許可されたグループの日報のみ検索・参照できる。
- 管理者は全社員の日報を検索・参照できる。
- 上長・管理者は日報の登録・編集を行わない。

| 画面ID | 機能ID | ストーリーID | 基本設計 |
| --- | --- | --- | --- |
| S-001 | F-001 | US-001 | [ログイン](ログイン/基本設計.html) |

| S-003 | F-002 | US-003 | [日報登録](日報登録/基本設計.html) |

承認状態の検索・表示と既存監査情報の参照は日報検索・登録の基本設計に従う。新規保存はDRAFT、編集保存は既存状態・監査情報を維持する。提出・承認・差戻しを実行する業務操作は対象外。
