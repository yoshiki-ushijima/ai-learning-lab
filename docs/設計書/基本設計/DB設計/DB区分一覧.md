# DB区分一覧

コード値、真偽値、開発・テスト用の初期マスタ値を管理する。テーブル・列の定義は[DB定義](DB定義/README.md)を参照する。

## ロール

| 値         | 表示上の意味 |
| ---------- | ------------ |
| `EMPLOYEE` | 社員         |
| `MANAGER`  | 上長         |
| `ADMIN`    | 管理者       |

## 承認状態

| 値         | 表示上の意味 |
| ---------- | ------------ |
| `DRAFT`    | 下書き       |
| `PENDING`  | 承認待ち     |
| `REJECTED` | 差戻し       |
| `APPROVED` | 承認済み     |

## 休日区分

| 値           | 表示名   | 勤務時刻 | 作業明細 |
| ------------ | -------- | -------- | -------- |
| `WORKDAY`    | 通常勤務 | 必須     | 許可     |
| `HOLIDAY`    | 休日     | 任意     | 許可     |
| `PAID_LEAVE` | 有給休暇 | 不要     | 不許可   |
| `AM_OFF`     | 午前休   | 必須     | 許可     |
| `PM_OFF`     | 午後休   | 必須     | 許可     |

休憩区分、勤務区分、案件、作業分類の具体的な初期値は `seed-master-data.sql` を正とする。

## 真偽値

| 値    | 意味               | 主な対象                                       |
| ----- | ------------------ | ---------------------------------------------- |
| TRUE  | 有効・必要・許可   | enabled、requires_work_time、allows_work_items |
| FALSE | 無効・不要・不許可 | enabled、requires_work_time、allows_work_items |

## 開発・テスト用の初期マスタ値

以下は[seed-master-data.sql](../../../../backend/src/main/resources/db/postgresql/seed-master-data.sql)の値。サンプル初期値であり、本番の案件・分類を固定する要件ではない。

| 対象            | ID           | 名称         | 表示順 | 有効 |
| --------------- | ------------ | ------------ | ------ | ---- |
| projects        | PROJECT-001  | サンプル案件 | 1      | TRUE |
| work_categories | CATEGORY-001 | 開発         | 1      | TRUE |
| break_types     | BREAK-001    | 標準休憩     | 1      | TRUE |
| work_time_types | WORKTIME-001 | 標準勤務     | 1      | TRUE |

### 休憩時間帯

| 休憩区分ID | 開始分 | 終了分 | 時刻         | 表示順 |
| ---------- | ------ | ------ | ------------ | ------ |
| BREAK-001  | 720    | 780    | 12:00〜13:00 | 1      |

### 勤務時間帯

| 勤務区分ID   | 通常開始分 | 通常終了分 | 深夜開始分 | 深夜終了分 |
| ------------ | ---------- | ---------- | ---------- | ---------- |
| WORKTIME-001 | 540        | 1080       | 1320       | 300        |

通常勤務は09:00〜18:00、深夜帯は22:00〜翌05:00（開始1320分、終了300分）。2026-10-27のユーザー回答により基本設計・受け入れ条件と統一した。社員への設定はユーザーの初期データで管理する。

現行の初期データは `seed-daily-report-search-data.sql` の勤務区分WT001を使用し、深夜開始1320分・終了300分である。上表のWORKTIME-001は仕様資料の例示IDであり、既存行の改名を意味しない。DBの稼働データへの更新は別途適用とし、保存済み日報の時間内訳はこの定義修正だけでは再計算しない。

休日区分の有効値・フラグ・表示順は同SQLを正とし、勤務時刻・明細の画面入力可否は[日報登録の業務ルール](../日報登録/基本設計.html#rules)に従う。既存の承認状態コードはDB互換性のため保持し、現行の画面・APIの機能を定義するものではない。
