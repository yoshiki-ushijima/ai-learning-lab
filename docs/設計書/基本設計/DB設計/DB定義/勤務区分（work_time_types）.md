# 勤務区分（work_time_types）

[DB設計の目次](../README.md)、[DB区分一覧](../DB区分一覧.md)。

## 業務上の意味と関係

勤務区分マスタを表す。
社員に紐づけ、実勤務時間を通常勤務時間、残業時間、深夜時間へ分解するために使用する。

- 勤務区分名の一意性は業務上の候補であり、現行物理DBの制約一覧に合わせて確認する。
- `regular_end_minutes` は `regular_start_minutes` より後にする
- 初回サンプルでは深夜時間帯を全勤務区分共通で `22:00-05:00` として扱う
- 深夜時間のDB値は `night_start_minutes = 1320`、`night_end_minutes = 300` とする。終了は翌日05:00を表し、22:00から24:00と00:00から05:00の時間帯に分けて扱う。2026-10-27のユーザー回答に基づき、DB区分一覧も同値へ統一した。
- 社員に設定されている勤務区分は、日報登録・編集時に自由変更しない

## 列定義

凡例: NULL可が「不可」はNOT NULL、キーが空欄の列は非キー列。列名・型・NULL可・キー・初期値は旧DB定義から維持する。

| 論理名                 | 物理名                  | 型             | NULL可 | キー・初期値 | 説明                  |
| ---------------------- | ----------------------- | -------------- | ------ | ------------ | --------------------- |
| 勤務区分ID             | `work_time_type_id`     | `VARCHAR(20)`  | 不可   | PK           | 勤務区分識別子        |
| 勤務区分名             | `work_time_type_name`   | `VARCHAR(120)` | 不可   |              | 画面表示に使用        |
| 通常勤務開始時刻（分） | `regular_start_minutes` | `INTEGER`      | 不可   |              | 通常勤務帯の開始分    |
| 通常勤務終了時刻（分） | `regular_end_minutes`   | `INTEGER`      | 不可   |              | 通常勤務帯の終了分    |
| 深夜勤務開始時刻（分） | `night_start_minutes`   | `INTEGER`      | 不可   |              | 深夜勤務帯の開始分    |
| 深夜勤務終了時刻（分） | `night_end_minutes`     | `INTEGER`      | 不可   |              | 深夜勤務帯の終了分    |
| 表示順                 | `display_order`         | `INTEGER`      | 不可   |              | 選択肢の表示順        |
| 有効フラグ             | `enabled`               | `BOOLEAN`      | 不可   | `TRUE`       | TRUE:有効、FALSE:無効 |
