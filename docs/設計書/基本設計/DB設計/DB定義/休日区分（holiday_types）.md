# 休日区分（holiday_types）

[DB設計の目次](../README.md)、[DB区分一覧](../DB区分一覧.md)。

## 業務上の意味と関係

休日区分マスタを表す。
日報登録時の入力可否、勤務時刻・作業明細の要否で使用する。

- `holiday_type` は一意
- 有給休暇は勤務時刻と作業明細を許可しない
- 休日は作業あり、作業なしの両方を許可するため、画面・業務ルールで勤務時刻と作業明細の有無を判定する

## 列定義

凡例: NULL可が「不可」はNOT NULL、キーが空欄の列は非キー列。列名・型・NULL可・キー・初期値は旧DB定義から維持する。

| 論理名             | 物理名               | 型             | NULL可 | キー・初期値 | 説明                             |
| ------------------ | -------------------- | -------------- | ------ | ------------ | -------------------------------- |
| 休日区分コード     | `holiday_type`       | `VARCHAR(20)`  | 不可   | PK           | 休日区分を識別するコード         |
| 休日区分名         | `holiday_type_name`  | `VARCHAR(120)` | 不可   |              | 画面表示に使用                   |
| 勤務時刻必須フラグ | `requires_work_time` | `BOOLEAN`      | 不可   |              | 勤務開始時刻・勤務終了時刻の要否 |
| 作業明細許可フラグ | `allows_work_items`  | `BOOLEAN`      | 不可   |              | 作業明細登録の可否               |
| 表示順             | `display_order`      | `INTEGER`      | 不可   |              | 選択肢の表示順                   |
| 有効フラグ         | `enabled`            | `BOOLEAN`      | 不可   | `TRUE`       | TRUE:有効、FALSE:無効            |
