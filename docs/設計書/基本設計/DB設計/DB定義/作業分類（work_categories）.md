# 作業分類（work_categories）

[DB設計の目次](../README.md)、[DB区分一覧](../DB区分一覧.md)。

## 業務上の意味と関係

作業分類マスタを表す。
日報作業明細で使用する。

- 作業明細から参照されている作業分類は物理削除しない

作業分類名は同じテーブル内で重複不可とする。有効・無効にかかわらず同一名称を許可せず、名称列に一意制約を設ける。比較対象は保存する名称の文字列とし、大小文字・全角半角の変換などの正規化は行わない。名称の一意制約は新規作成用DDLで定義する。既存テーブルへの追加には[DB共通設計](../DB共通設計.md#db設計方針)に従い別途移行手順が必要となる。

## 列定義

凡例: NULL可が「不可」はNOT NULL、キーが空欄の列は非キー列。名称列の一意制約は設計として追加する。

| 論理名     | 物理名               | 型             | NULL可 | キー・初期値 | 説明                               |
| ---------- | -------------------- | -------------- | ------ | ------------ | ---------------------------------- |
| 作業分類ID | `work_category_id`   | `VARCHAR(20)`  | 不可   | PK           | 作業分類識別子                     |
| 作業分類名 | `work_category_name` | `VARCHAR(120)` | 不可   | UNIQUE       | 画面表示に使用。同一名称の重複不可 |
| 表示順     | `display_order`      | `INTEGER`      | 不可   |              | 選択肢の表示順                     |
| 有効フラグ | `enabled`            | `BOOLEAN`      | 不可   | `TRUE`       | `TRUE`:有効、`FALSE`:無効          |
