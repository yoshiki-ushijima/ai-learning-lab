# 基本設計

画面IDごとに基本設計HTMLを1つ管理する。

| 画面ID | 機能ID | ストーリーID | 基本設計 |
| --- | --- | --- | --- |
| S-001 | F-001 | US-001 | [ログイン](ログイン/基本設計.html) |
| S-002 | F-004 | US-002 | [日報カレンダー・一覧](日報検索/基本設計.html) |
| S-003 | F-002 | US-003 | [日報登録](日報登録/基本設計.html) |
| S-004 | F-003 | US-003 | [日報編集](日報編集/基本設計.html) |
| S-005 | F-005 | US-002 | [日報詳細](日報詳細/基本設計.html) |

## HTML内のタブ

各画面の仕様・入力チェック・業務ルール・モックを参照する。モックは対象画面のみを表示する。

- 日報登録・編集に共通する入力チェック、休日区分、時間計算は日報登録に定義し、日報編集から参照する。
- 日報検索・詳細に共通する閲覧権限は日報検索に定義し、日報詳細から参照する。
- ストーリー・機能・画面・条件・ルールの既存IDを使う。
